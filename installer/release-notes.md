## 🆕 1.2.7
- 🇫🇷 Volant : correction pour les volants qui apparaissent deux fois dans Windows (ex. Fanatec) : le bouton radio est maintenant bien détecté en jeu. Merci à l'utilisateur qui l'a signalé !
- 🇬🇧 Wheel: fix for wheels that show up twice in Windows (e.g. Fanatec): the radio button is now detected in game. Thanks to the user who reported it!
- 🇫🇷 Interface plus claire : en haut, seulement les 3 boutons de course (🔊 Radio, 🤫 Silence, 👀 Spotter, allumés ou éteints) ; tous les réglages (voix, volume, encouragements, micro, bouton radio, raccourcis, couleur, langue) sont rangés dans le panneau ⚙️ Réglages. Les pneus affichent « – » au lieu de -273 °C quand le jeu ne donne pas encore leurs données.
- 🇬🇧 Cleaner interface: only the 3 race buttons stay at the top (🔊 Radio, 🤫 Quiet, 👀 Spotter, lit or dimmed); all settings (voice, volume, encouragement, mic, radio button, shortcuts, colour, language) are in the ⚙️ Settings panel. Tyres show "–" instead of -273 °C when the game hasn't sent their data yet.
- 🇫🇷 Encouragements réglables : menu 💬 dans le tableau de bord, Discret (juste les infos), Normal ou Motivant (plus souvent et plus varié).
- 🇬🇧 Adjustable encouragement: 💬 menu on the dashboard, Low-key (info only), Normal or Hype (more often, more varied).
- 🇫🇷 Places gagnées : après le 1er tour (« Bon départ, tu as gagné 3 places ! ») et pendant la course à chaque place gagnée ou perdue (sauf autour des arrêts aux stands).
- 🇬🇧 Places gained: after lap 1 ("Good start, you gained 3 places!") and during the race for every place gained or lost (except around pit stops).


## 🇫🇷 Installation
Télécharge **ApexRadio-Setup.exe** ci-dessous, lance-le, clique sur Suivant. C'est tout : Python et tous les composants sont inclus.
Windows peut afficher « Windows a protégé votre ordinateur » (l'appli n'est pas encore signée) : clique sur **Informations complémentaires**, puis **Exécuter quand même**.
Au premier lancement, la voix et la reconnaissance vocale se téléchargent (quelques minutes, une seule fois).

## 🇬🇧 Install
Download **ApexRadio-Setup.exe** below, run it, click Next. That's it: Python and all components are included.
Windows may show "Windows protected your PC" (the app isn't signed yet): click **More info**, then **Run anyway**.
On first launch, the voice and speech recognition download (a few minutes, only once).
