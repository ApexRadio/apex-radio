# Apex Radio pour Stream Deck

Plugin Stream Deck pour [Apex Radio](https://github.com/ApexRadio/apex-radio) (Windows). Il parle à l'appli
Apex Radio sur le même PC (`http://127.0.0.1:8765`), rien ne passe par Internet.

Touches : Radio (parler), Info en direct (place, essence, écarts, box, temps au tour), Spotter oui/non,
Mode silence, Radio oui/non, Répète, Question (phrase au choix), Lancer LMU.

Construire : `npm install` puis `npm run pack` → `dist/com.apexradio.streamdeck.streamDeckPlugin`
(double-clic pour l'installer). Nécessite Apex Radio 1.2.11 ou plus récent.
