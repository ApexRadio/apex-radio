APEX RADIO - TEST IRACING
=========================

Merci de tester ! Cet outil lit les donnees qu'iRacing partage officiellement (le meme
systeme que les applis de telemetrie) et les enregistre. Il ne modifie RIEN dans le jeu.

AVANT : installe Apex Radio (gratuit) : https://github.com/ApexRadio/apex-radio/releases/latest
        (l'outil utilise le Python fourni avec Apex Radio)

1. Dezippe ce dossier ou tu veux (par exemple sur le Bureau).
2. Double-clique sur "Lancer le test iRacing.bat". Une fenetre noire s'ouvre.
3. Lance iRacing et fais une COURSE d'au moins 15-20 minutes (contre l'IA ou en ligne),
   si possible avec un arret au stand. Laisse la fenetre noire ouverte.
4. A la fin, ferme la fenetre noire et envoie-moi ce fichier :
      Documents\Apex Radio\iracing_test\RESULTATS_iRacing.zip
   Il contient tes chronos, positions, essence, et ton pseudo iRacing / celui des autres
   pilotes de la course. Rien d'autre.

Si Windows affiche un ecran bleu "Windows a protege votre ordinateur" :
"Informations complementaires" puis "Executer quand meme".

APEX RADIO - IRACING TEST

Thanks for testing! This tool reads the data iRacing officially shares (the same system
telemetry apps use) and saves it. It changes NOTHING in the game.

BEFORE: install Apex Radio (free): https://github.com/ApexRadio/apex-radio/releases/latest
        (the tool uses the Python that comes with Apex Radio)

1. Unzip this folder anywhere (for example on your Desktop).
2. Double-click "Lancer le test iRacing.bat". A black window opens.
3. Start iRacing and do a RACE of at least 15-20 minutes (AI or online), ideally with a
   pit stop. Keep the black window open.
4. When done, close the black window and send me this file:
      Documents\Apex Radio\iracing_test\RESULTATS_iRacing.zip
   It contains your lap times, positions, fuel, and your iRacing name / the other drivers'
   names from that race. Nothing else.
